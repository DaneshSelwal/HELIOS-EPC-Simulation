# Department 16: External Parties & Counterparties (`EX-01` to `EX-08`)

This directory houses the persona instruction files for the 8 simulated external stakeholders interacting with the HELIOS 100MW Solar PV + 33/220kV GSS EPC Consortium:

1. **PATRON (`EX-01`)** — Client / Employer Representative (FIDIC Yellow Book Employer / SPV)
2. **AUDITOR (`EX-02`)** — Owner's / Lender's Independent Engineer (EBRD / IFC / ADB Technical Advisor)
3. **GRIDMASTER (`EX-03`)** — National Grid Utility Representative (UzbekEnergo / NEGU Dispatch & Protection)
4. **LUMINOS (`EX-04`)** — Tier-1 PV Module Vendor (172,800 pcs 580W N-Type TOPCon Bifacial)
5. **INVERSA (`EX-05`)** — Central Inverter, 33kV MV Skid & Power Plant Controller (PPC) Vendor (25 x 4.0MVA Skids)
6. **POWERTRANS (`EX-06`)** — 220kV/33kV 100MVA Main Power Transformer (MPT) & 220kV GIS Switchgear Vendor
7. **INSPECTOR (`EX-07`)** — Local Authority / Statutory Inspector (Uzenergoinspeksiya, Territorial GASN, Ecology/Goskompriroda, SanPiN)
8. **CERTIFIER (`EX-08`)** — Independent Certifier (Milestone Verification, Mechanical Completion, IEC 61724 PR Test & PAC/FAC Certification)
